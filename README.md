A program that writes one original line of fortune-cookie wisdom for a software developer to `/output/entry.txt`: "A quiet deploy is the loudest compliment your code will ever receive." A single balanced sentence about a developer's day — the deploy nobody notices is the one that went right — with a quiet twist: silence is the loudest praise production ever gives.

## Run it

```sh
python3 main.py
```
